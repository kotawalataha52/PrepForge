PrepForge is a comprehensive MERN-stack platform designed to revolutionize the way candidates prepare for technical interviews. By leveraging artificial intelligence, it provides real-time feedback, ATS resume analysis, and an immersive user experience.

## ✨ Features
- **Intelligent Dashboard**: Track your interview history, average scores, and AI-recommended focus areas.
- **Resume Intel**: Upload your resume to get instant ATS parsing, formatting suggestions, and AI-driven feedback.
- **Dynamic Workflows**: Engage in simulated tech interviews with customized parameters and real-time evaluation.
- **Premium Dark UI**: A highly responsive, sleek interface built with React, Tailwind CSS, and Framer Motion.

## 🛠️ Tech Stack
- **Frontend**: React, Vite, Tailwind CSS, Framer Motion
- **Backend**: Node.js, Express.js, Socket.io
- **Database**: MongoDB (Mongoose)
- **AI Integration**: Powered by Google Gemini API for fast, high-quality responses.

## 🚀 Getting Started

### Prerequisites
- Node.js
- MongoDB Atlas cluster (or local instance)

### Installation
1. **Clone the repository:**
   ```bash
   git clone https://github.com/kotawalataha52/PrepForge.git
   cd PrepForge
   ```

2. **Setup Backend:**
   ```bash
   cd backend
   npm install
   # Create a .env file with your MONGO_URI, JWT_SECRET, and GEMINI_API_KEY
   npm run dev
   ```

3. **Setup Frontend:**
   ```bash
   cd ../frontend
   npm install
   npm run dev
   ```

4. Open `http://localhost:5173` in your browser to Start Foraging!
